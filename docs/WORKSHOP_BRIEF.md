# Workshop Brief — RAG Battle Royale

## Mission

Acme Cloud has a growing internal knowledge base and engineers are
struggling to find accurate answers quickly. Your team has been asked to
build an AI knowledge assistant.

You have **60 minutes** to improve the baseline RAG system and **20 minutes**
to polish and test your solution. Your system will then be evaluated against
questions you have never seen.

**Highest score wins.**

## Your goal

Build the most accurate, grounded, and efficient RAG system possible.

## Remember

- Correctness matters more than complexity.
- Retrieval quality matters.
- Hallucinations are heavily penalized.
- Unknown information should result in an explicit "not specified" answer.
- Your system will be tested on unseen questions.
- You will not know the evaluation questions in advance.

## Agenda

| Time | Activity |
|---|---|
| 0–10 min | Introduction + rules |
| 10–20 min | Baseline demo |
| 20–80 min | 🔥 Battle — build |
| 80–90 min | Final testing / freeze |
| 90–110 min | Hidden evaluation |
| 110–120 min | Leaderboard + winners |

See [PARTICIPANT_RULES.md](PARTICIPANT_RULES.md) for the full rules and
scoring breakdown.
